# Лабораторна робота №1: Проєктування AI-агента для автоматизації розробки та CI/CD

* **Студент:** Банада Владислав
* **Варіант:** 1 (C++, CMake, GoogleTest / CTest)
* **GitHub:** [@vladyslavbanada](https://github.com/vladyslavbanada)

## Опис проєкту
Проєкт містить конфігурацію автономного AI-агента **Build & DevOps Engineer**, розробленого для автоматизації створення кросплатформних C++ додатків за допомогою GitHub Copilot.

Агент автоматизує:
1. Створення шаблону C++ проєкту (Scaffolding).
2. Налаштування кросплатформної збірки через CMake та запуск юніт-тестів на GoogleTest.
3. Генерацію кросплатформного CI/CD конвеєра в GitHub Actions (Windows, Linux, macOS) через скрипти запуску `ci.bat` та `ci.sh`.
4. Верифікацію та валідацію репозиторію без небажаних модифікацій (`check`).

## Спосіб запуску агента
Агент керується через orchestrator-команду:
* У **Copilot Chat** (у гілці `feature/...`) виконати запит:
  ```text
  Запусти /init згідно з інструкцією в .github/prompts/init.prompt.md
  ```
* Для перевірки стану та коректності проєкту:
  ```text
  Запусти /check згідно з .github/prompts/check.prompt.md
  ```
